Agent（智能体）

学习目标

  • 理解Agent的核心定义和基本特征
  • 掌握Agent的四大核心模块及其作用
  • 能够区分Agent与聊天机器人、自动脚本的差异

个人解释

Agent就是一个能自主完成任务的"数字员工"。你给它一个目标，它会自己思考怎么做、调用什么工具、按什么步骤执行，最后把结果给你。它不像传统程序那样只会按固定规则运行，而是有一定的"自主判断能力"。

核心机制 / 组成部分

  • 感知模块：接收外部信息（用户指令、环境数据）
  • 决策模块：根据接收到的信息，决定下一步做什么
  • 执行模块：调用工具（如搜索、计算器、API）执行动作
  • 记忆模块：存储历史对话或任务状态，保证连续性

简单说：感知 → 思考 → 行动 → 记忆，循环进行。

具体应用场景

场景：智能客服机器人
你是一家电商公司的运营。用户发来消息说"我买的手机屏幕裂了"。Agent自动判断：这是售后问题 → 调取订单信息 → 核实购买记录 → 生成退换货指引 → 如果用户不满意，自动转接人工。整个过程中，Agent不需要你写一堆 if-else 规则，它自己"理解"并处理了。

容易混淆的问题 / 使用边界

  • Agent ≠ 聊天机器人：聊天机器人只会"对话"，Agent会"行动"（比如帮你订票、查数据、发邮件）
  • Agent ≠ 自动脚本：脚本按固定步骤执行，Agent能根据情况灵活调整
  • Agent的能力上限取决于它被允许使用的工具和模型的推理能力，不是万能的
