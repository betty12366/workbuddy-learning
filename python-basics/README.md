# Python 基础语法 · 可运行教材

5 个文件，一个主题一个文件，按序号从上往下读、逐个运行。
注释里的 `# 输出：` 就是那行代码跑出来应该得到的值 —— 先自己猜，再跑，对不上就停下来看那一节。

## 怎么跑

在 VS Code 里打开这个文件夹，然后：

1. 装官方 Python 扩展（Microsoft 的 `Python`）
2. 打开任意 `.py` 文件，点右上角 ▷ **Run Python File**（或按 `Ctrl+F5`）
3. 输出在下方终端里，和注释里的 `# 输出：` 逐行对着看

命令行也行：`python 01_variables.py`

## 每个文件里的结构

1. 顶部 docstring：这章讲什么、学完能做什么
2. 按 `# 1. 小节名` 推进：讲解注释 → 可运行代码 → `# 输出：`
3. 若干「常见坑」：错在哪、为什么错、正确怎么写
4. 末尾「自测题」：先自己写，写不出来再把参考答案的注释取消掉对照

## 自测题怎么用

每道题的参考答案都**整段注释掉**了。做法是先自己写、跑通；
卡住了再把题目下方的答案块取消注释，对着输出看差在哪。

个别题目是故意写错的（比如 05 第 7 题让你亲眼看到 `UnboundLocalError`），
那种地方注释里会写明，按说明操作即可。

## 一点说明

- 代码在 Python 3.13 上逐个跑过，全部零报错。
- 只用到 Python 3.8+ 的语法；`match/case` 需要 3.10+，`:=` 需要 3.8+，都在小节里标注了。
- 例子尽量用成绩、分数、及格率这类统计场景，跟课程能对上。
